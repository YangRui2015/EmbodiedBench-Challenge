Submission Guidelines

The EvalAI submission portal will be used for the EmbodiedBench Challenge at the CVPR 2026 Workshop on Foundation Models Meet Embodied Agents (FMEA) Challenges. The submission deadline is May 1, 2026, 23:59 AoE (Anywhere on Earth).

First, run your model or agent with the official EmbodiedBench code to generate rollout trajectories and result files for EB-ALFRED and EB-Navigation. A typical raw rollout directory for an environment looks like: 

eb_alfred/model_experiment/
|-- summary_all.json
|-- base/
|   |-- config.txt
|   |-- episode_1_step_19.json
|   |-- episode_2_step_10.json
|   |-- ...
|   |-- episode_50_step_11.json
|   |-- images/
|   |   |-- episode_1/
|   |   |-- episode_2/
|   |   |-- ...
|   |   `-- episode_50/
|   `-- results/
|       |-- episode_1_final_res.json
|       |-- episode_2_final_res.json
|       |-- ...
|       |-- episode_50_final_res.json
|       `-- summary.json
`-- common_sense/
    |-- config.txt
    |-- episode_1_step_14.json
    |-- episode_2_step_19.json
    |-- ...
    |-- episode_50_step_19.json
    |-- images/
    |   |-- episode_1/
    |   |-- ...
    |   `-- episode_50/
    `-- results/
        |-- episode_1_final_res.json
        |-- ...
        |-- episode_50_final_res.json
        `-- summary.json

Use the provided JSON extraction script to copy only the episode JSON files into a compact results/ directory while preserving the environment, experiment, and subset directory structure. The submitted zip file must contain the two environment roots results/eb_alfred/ and results/eb_navigation/. Then compress the results/ directory as a zip file and submit that zip file to EvalAI. 

python copy_json.py --source /path/to/embodiedbench_rollouts --output results
zip -r results.zip results

The EvalAI evaluator will extract the submitted zip file and compute each environment's average success rate and average episode length from the submitted episode JSON files. Do not modify hidden test labels, manually label held-out test examples, or use human-in-the-loop labeling on the held-out test set.

Commercial APIs are not allowed. Open-source base models should be limited to fewer than 10B parameters. Participants should fine-tune their own models for embodied decision making, or design agent skills and frameworks that enable strong performance.
