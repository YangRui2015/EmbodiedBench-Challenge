Submission Guidelines

The EvalAI submission portal is used for the EmbodiedBench Challenge at the CVPR 2026 Workshop on Foundation Models Meet Embodied Agents (FMEA) Challenges. Stage 1 runs from April 15, 2026 to May 22, 2026, 23:59 AoE. Stage 2 runs from May 23, 2026 to May 28, 2026, 23:59 AoE. All times are Anywhere on Earth (UTC−12).

First, run your model or agent with the official EmbodiedBench code to generate rollout trajectories for EB-ALFRED and EB-Navigation. A typical raw rollout directory looks like: 

eb_alfred/model_experiment/
|-- summary_all.json
|-- base/
|   |-- episode_1_step_19.json
|   |-- episode_2_step_10.json
|   |-- ...
|   |-- images/
|   `-- results/
|       |-- episode_1_final_res.json
|       `-- ...
`-- common_sense/
    |-- episode_1_step_14.json
    |-- ...
    |-- images/
    `-- results/
        |-- episode_1_final_res.json
        `-- ...

Next, use copy_json.py from the EmbodiedBench repository to extract only the episode JSON files. Run the script once per environment: 

python copy_json.py --source path/to/running/eb_alfred/model_experiment \
                    --output submission_folder/eb_alfred
python copy_json.py --source path/to/running/eb_nav/model_experiment \
                    --output submission_folder/eb_nav

This produces the following compact structure: 

submission_folder/
|-- eb_alfred/
|   `-- model_experiment/
|       |-- base/
|       |   |-- episode_1_step_19.json
|       |   `-- ...
|       `-- common_sense/
|           |-- episode_1_step_14.json
|           `-- ...
`-- eb_nav/
    `-- model_experiment/
        |-- base/
        |   |-- episode_1.json
        |   `-- ...
        `-- common_sense/
            |-- episode_1.json
            `-- ...

Finally, compress submission_folder/ and submit the zip to EvalAI: 

cd submission_folder && zip -r ../submission.zip . && cd ..

The evaluator will extract the zip, scan all episode JSON files under eb_alfred/ and eb_nav/, compute each environment's average success rate and average episode length, and update the leaderboard automatically.

Commercial APIs are not allowed. Open-source base models should be limited to fewer than 10B parameters. Do not modify episode JSON files or use human-in-the-loop labeling on held-out examples.
