Final Held-out Test Phase

This phase evaluates the top 5 teams from Stage 1 on a held-out test set for the EmbodiedBench Challenge at the CVPR 2026 Workshop on Foundation Models Meet Embodied Agents (FMEA) Challenges. The held-out tasks are drawn from EB-ALFRED and EB-Navigation and will be released after Stage 2 concludes.

This phase runs from May 25, 2026 to May 28, 2026, 23:59 AoE (Anywhere on Earth).

Eligibility

Only the top 5 teams from Stage 1 (Qualification / Validation Phase) are invited to participate in Stage 2. Invited teams will be notified by the organizers with a private submission link.

Submission Format

Each team is allowed exactly one submission in this phase. Submissions are made via the private link provided by the organizers, not through the standard EvalAI upload interface.

The submitted system must be runnable by the organizers against the EmbodiedBench held-out environments via one of the following two options:

Option A — vLLM-compatible model server:

Submit a fine-tuned or adapted model that can be served using vLLM's OpenAI-compatible server. The organizers will launch the model with: 

vllm serve <your-model> --host 0.0.0.0 --port 8000

The model will be evaluated using the standard EmbodiedBench pipeline. Provide the model path or Hugging Face model ID and any required vllm serve arguments in your submission.

Option B — Custom agent framework:

Design and submit a custom agent framework by modifying the planner/ directory of the EmbodiedBench repository. Teams may customize planner.py and related files to implement novel prompting strategies, reasoning chains, action selection logic, and multi-turn memory. Teams may also provide a custom server.py for their model backend if needed.

Constraints: teams may only modify files under planner/ and add new supporting modules. Evaluator code, environment code, and metric computation must remain unchanged.

The organizers will run evaluation using: 

python -m embodiedbench.main env=eb-alf model_type=custom exp_name=<team>
python -m embodiedbench.main env=eb-nav model_type=custom exp_name=<team>

Submission Package

Regardless of which option you choose, submit a zip archive containing:

  • Your modified code (model weights via Hugging Face model ID / link, or code for Option B)
  • A README.md with step-by-step instructions for setting up and launching your system
  • A requirements.txt or equivalent listing all dependencies
  • A startup script and any required arguments
  • A brief technical description of your approach (1–4 pages)

The final ranking will be determined by the held-out test set evaluation results. The held-out data will be released publicly after Stage 2 concludes. Winners will be announced on May 31, 2026.

Note: The deadline for submitting the Stage 2 package is May 26, 2026 (AoE), to allow sufficient time for online evaluation and to address any engineering issues related to customization from participating teams. The Phase 2 portal closes on May 28, 2026, 23:59 AoE.
