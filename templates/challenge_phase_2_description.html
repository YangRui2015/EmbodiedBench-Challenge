Final Held-out Test Phase

This phase evaluates the top 5 teams from Stage 1 on a held-out test set for the EmbodiedBench Challenge at the CVPR 2026 Workshop on Foundation Models Meet Embodied Agents (FMEA) Challenges.

This phase runs from May 25, 2026 to May 28, 2026, 23:59 AoE (Anywhere on Earth).

Eligibility

Only the top 5 teams from Stage 1 (Qualification / Validation Phase) are invited to participate in Stage 2. Invited teams will be notified by the organizers with a private submission link.

Submission Format

Each team is allowed exactly one submission in this phase. Submissions are made via the private link provided by the organizers, not through the standard EvalAI upload interface.

The submitted system must be runnable by the organizers against the EmbodiedBench environments via one of the following two interfaces:

Option A — vLLM-compatible model server:

Submit a fine-tuned or adapted model that can be served using vLLM's OpenAI-compatible server. The organizers will launch the model with: 

vllm serve <your-model> --host 0.0.0.0 --port 8000

The model will then be evaluated against the held-out test set using the standard EmbodiedBench pipeline. Provide the model path or Hugging Face model ID and any required vllm serve arguments in your submission.

Option B — Custom agent framework server:

Submit a custom agent framework that exposes an HTTP server on a specified port and implements an OpenAI-compatible chat completions interface. The server must accept POST requests at /v1/chat/completions in the following format: 

POST /v1/chat/completions
{
  "model": "<model-name>",
  "messages": [
    {"role": "user", "content": [
      {"type": "text", "text": "<instruction>"},
      {"type": "image_url", "image_url": {"url": "data:image/jpeg;base64,<...>"}}
    ]}
  ]
}

and return a response in the standard OpenAI chat completions format. The organizers will start your server and point the EmbodiedBench evaluation pipeline to it. Provide a startup script and any required dependencies in your submission.

Submission Package

Regardless of which option you choose, your submission package should include:

  • Model weights or code repository (e.g., Hugging Face model ID, GitHub link, or compressed archive)
  • A README with step-by-step instructions for launching the server
  • A complete list of dependencies (requirements.txt or equivalent)
  • Any vllm serve flags or startup script arguments needed
  • A brief technical report describing your approach (1–4 pages)

The final ranking will be determined by the held-out test set evaluation results. The deadline is May 28, 2026, 23:59 AoE (Anywhere on Earth). Winners will be announced on May 31, 2026.
