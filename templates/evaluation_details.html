Evaluation Details

Submissions will be evaluated on the ability to complete embodied tasks from visual observations and language instructions in EB-ALFRED and EB-Navigation. The primary ranking metric is Overall average task success rate across the evaluated tasks and environments.

Higher Overall average task success rate is better. If two submissions have the same Overall average task success rate, ties will be resolved by average number of steps, with fewer steps ranked higher. We will not report capability-oriented breakdowns for the challenge leaderboard.

Submissions should include the original trajectory files and results produced by running the official EmbodiedBench code. Commercial APIs are not allowed. Participants should fine-tune their own models for embodied decision making, or design agent skills and frameworks that enable strong performance.

To emphasize algorithmic design rather than model scale, open-source base models used by participants should be limited to fewer than 10B parameters.

In the first stage, from May 1 to May 22, 2026, participants should run the official EmbodiedBench code and submit the extracted rollout trajectory JSON files. A typical raw EmbodiedBench rollout directory contains a top-level summary_all.json, subset folders such as base/ and common_sense/, per-episode step files such as episode_1_step_19.json, image folders, and results/episode_*_final_res.json files.

Before submitting, participants should use the provided JSON extraction script to copy only the episode JSON files into a compact results/ directory while preserving the environment, experiment, and subset directory structure. The zip file submitted to EvalAI should contain results/eb_alfred/ and results/eb_navigation/.

After submission, the evaluator will extract the submitted zip file, scan the episode JSON files, compute the average success rate for each environment, and compute the average episode length. The leaderboard will use Overall average task success rate as the primary ranking metric and average episode length as the tie-breaker.

In the second stage, from May 23 to May 30, 2026, the top 5 teams will be invited to submit a report and may be asked to provide their models or framework code using the original APIs to interact with EmbodiedBench environments. We will evaluate these submissions on a held-out set to determine the final ranking.

The first-stage submission deadline is May 22, 2026, 23:59 AoE (Anywhere on Earth). The second-stage deadline is May 30, 2026, 23:59 AoE (Anywhere on Earth).
