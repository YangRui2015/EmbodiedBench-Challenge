Evaluation Details

Submissions will be evaluated on the ability to complete embodied tasks from visual observations and language instructions in EB-ALFRED and EB-Navigation. The primary ranking metric is Overall Score, which is the average task success rate across EB-ALFRED and EB-Navigation.

Higher Overall Score is better. If two submissions have the same Overall Score, ties will be resolved by Average Steps (the average of per-environment average episode length), with fewer steps ranked higher.

Submissions must include the original trajectory files produced by running the official EmbodiedBench code. Commercial APIs are not allowed. To emphasize algorithmic design rather than model scale, open-source base models should be limited to fewer than 10B parameters. Participants should fine-tune their own models for embodied decision making, or design agent skills and frameworks that enable strong performance.

Stage 1 (April 15 – May 22, 2026): Run the official EmbodiedBench code to generate rollout trajectories for EB-ALFRED and EB-Navigation. Use the provided copy_json.py script to extract episode JSON files and prepare the submission zip. Submit the zip file to EvalAI. The evaluator will automatically compute the average success rate and average episode length for each environment and update the leaderboard.

Stage 2 (May 23 – May 28, 2026, 23:59 AoE): The top 5 teams from Stage 1 will be invited via a private organizer link to submit their model or agent framework for held-out test evaluation. Each team may submit exactly once. The submission must be a vLLM-servable model or a custom agent framework that exposes an OpenAI-compatible HTTP server. The final ranking is determined by held-out test performance.

Submission format: Use copy_json.py from the EmbodiedBench repository to extract episode JSON files. Run the script once per environment, then compress the output folder: 

python copy_json.py --source path/to/running/eb_alfred/model_experiment \
                    --output submission_folder/eb_alfred
python copy_json.py --source path/to/running/eb_nav/model_experiment \
                    --output submission_folder/eb_nav
cd submission_folder && zip -r ../submission.zip . && cd ..

The resulting zip contains eb_alfred/ and eb_nav/ at the top level. After submission, the evaluator extracts the zip, scans all episode JSON files, and computes leaderboard metrics automatically.

The Stage 1 deadline is May 22, 2026, 23:59 AoE. The Stage 2 deadline is May 28, 2026, 23:59 AoE. All times are Anywhere on Earth (UTC−12).
